# Vendored fonts

LiberationSans-Regular.ttf and LiberationSans-Bold.ttf, Liberation Fonts 2.1.5
(https://github.com/liberationfonts/liberation-fonts, release 2.1.5), unmodified.
Liberation Sans is metric-compatible with Arial. The fonts are licensed under the
SIL Open Font License 1.1; the full text is in LICENSE-LiberationSans.txt. They are
used only by scripts/figure_style.py to draw the figures.
